# Manual icon overrides

Drop an image here named exactly as listed below and it's picked up automatically - no code
changes needed. `components/WeaponIcon.jsx` checks this folder first, before the auto-baked
`images/skyblock/` icon and before the generic vanilla-material fallback (see `buildCandidates`
in that file). If a file listed here doesn't exist yet, the existing fallback chain is used as
normal (a missing manual file is not an error).

**The file has to be `.webp`** - that's what `lib/icons.js` asks for, here and in every other
icon folder. If what you have is a PNG, drop it in anyway and run
`node worker/scripts/compress-icons.mjs`, which converts it losslessly and removes the PNG.

Recommended size: 100x100 (matches `apply-skull-head-icons.mjs`'s HEAD_RENDER_SIZE), transparent
background, isometric head-style like the rest of `images/skyblock/`.

This is specifically for ids where `worker/scripts/apply-skull-head-icons.mjs` can't produce a
real render - mc-heads.net silently returns a default Steve-skin render (not an error) for these
specific texture hashes even though the underlying Mojang texture is real and valid; see that
script's own comment on `saveHeadRender` for the full writeup. Re-running the auto-update
pipeline (`worker/scripts/update-data.mjs`) will keep reporting these as missing/unresolvable -
that's expected, it's not a regression.

## UI chrome icons (fixed path, not part of the id-keyed fallback above)

These are referenced directly by a hardcoded `/images/manual/<name>.webp` path in specific
components - not looked up via `WeaponIcon.jsx`'s item-id fallback chain, so there's no
melee/vanilla fallback if missing (just a broken image icon until the file exists).

- `mage_mode.webp` - icon next to the "Mage Mode" toggle button, `pages/DamageSources.jsx`.
  User-provided art (a purple/black "corrupted" cube), not sourced from NEU-REPO.
- `tutorial_icon.webp` / `calculations_icon.webp` - drawer menu icons for Tutorial/Calculations,
  `components/TopBar.jsx`'s `MENU_LINKS`. Custom-head renders (not real Skyblock items), fetched
  from mc-heads.net using texture hashes sourced from minecraft-heads.com (Info Books / Stack of
  Newspapers).
