# Manual icon overrides

Drop a PNG here named exactly as listed below and it's picked up automatically — no code
changes needed. `components/WeaponIcon.jsx` checks this folder first, before the auto-baked
`images/skyblock/` icon and before the generic vanilla-material fallback (see `buildCandidates`
in that file). If a file listed here doesn't exist yet, the existing fallback chain is used as
normal (a missing manual file is not an error).

Recommended size: 100x100 (matches `apply-skull-head-icons.mjs`'s HEAD_RENDER_SIZE), transparent
background, isometric head-style like the rest of `images/skyblock/`.

This is specifically for ids where `worker/scripts/apply-skull-head-icons.mjs` can't produce a
real render — mc-heads.net silently returns a default Steve-skin render (not an error) for these
specific texture hashes even though the underlying Mojang texture is real and valid; see that
script's own comment on `saveHeadRender` for the full writeup. Re-running the auto-update
pipeline (`worker/scripts/update-data.mjs`) will keep reporting these as missing/unresolvable —
that's expected, it's not a regression.
